# Техасская программа для iPhone

Нативное офлайн-приложение на SwiftUI с выбором одной из двух силовых программ: 12-недельного `FreedomTexas` и 7-недельного цикла «Верх / Низ» на четыре тренировки в неделю. Все данные и отметки хранятся локально.

## Возможности

- iOS 17+, SwiftUI и SwiftData;
- выбор программы при первом запуске;
- 12 недель × 3 тренировочных дня;
- «Верх / Низ»: 7 недель × 4 дня и 14 волновых жимовых тренировок;
- отдельный раздел **«Жим 14»**: вся волна жима по подходам, проценты от 1ПМ, график верхних весов, метки «негатив / тест / рекорд» и собственный прогресс;
- переход из тренировки дня прямо в нужную жимовую тренировку волны;
- отметки связаны: жимовая тренировка волны и её день программы отмечаются вместе;
- волна жима не привязана к дню недели: вспомогательные упражнения берутся из дня программы, а жим — следующий по счёту в волне, поэтому пропуск одного дня не ломает порядок жима;
- привязка к календарю: экран «Сегодня» знает текущий день недели и дату, показывает «Сегодня / Завтра / Через N дн.» и отмечает дни отдыха;
- два режима расписания: «По дням недели» (по умолчанию) — у каждого дня недели свой счётчик, в понедельник всегда понедельничная тренировка первой невыполненной недели; «Очередь» — невыполненные идут строго подряд по ближайшим тренировочным дням;
- дни недели тренировок настраиваются (по умолчанию Пн/Вт/Чт/Пт для «Верх / Низ» и Пн/Ср/Пт для «Техаса»);
- несколько профилей: у каждого своя программа, максимумы, расписание и отметки, переключение и переименование в настройках;
- «Начать отсюда» — ручной выбор текущей тренировки после переустановки: всё до неё отмечается выполненным, а она встаёт на ближайшую дату своего дня недели;
- отметка по подходам: точки под упражнением, закрытый подход сам запускает отдых, а последний подход дня закрывает тренировку;
- таймер отдыха на 3 / 5 / 10 минут: отсчёт поверх вкладок, Live Activity в Dynamic Island и на экране блокировки, вибрация и уведомление по окончании;
- разбор веса: какие блины вешать на сторону и разминочные подходы до рабочего веса;
- пикирование подключено к плану: после запуска «Сегодня» и «План» показывают пиковый цикл, отметки основной программы сохраняются отдельно;
- история выполненных тренировок с датами и график рабочих весов приседа, жима и тяги;
- виджеты: на домашнем экране следующая тренировка с неделей, типом дня и номером жима, на экране блокировки круглый и строчный варианты;
- резервная копия: выгрузка и загрузка всех профилей файлом, формат общий с версией для Android;
- автоматическое округление веса с шагом 2,5 кг;
- уровни пикирования «Начальный» и «Средний»;
- выбор дополнительной тяги, рук, кора, спины и вертикального жима;
- локальное сохранение профиля, выполненных дней и отмеченных жимовых тренировок;
- полный сброс к стартовому выбору программы;
- одна иконка приложения — чёрная, без выбора вариантов;
- градиентный интерфейс с «жидкими» карточками, каскадным появлением, кольцами прогресса и тактильным откликом;
- светлая/тёмная тема, Dynamic Type, поддержка «Уменьшения движения»;
- unsigned IPA через GitHub Actions для подписи в Sideloadly.

## Цели проекта

- `TexasProgram` — приложение;
- `TexasProgramTests` — юнит-тесты;
- `StrainWidgets` — расширение с Live Activity таймера отдыха и виджетами. Собирается автоматически как зависимость приложения и встраивается внутрь `.app`.

Виджетам нужен общий контейнер `group.com.texasprogram.app`, объявленный в `TexasProgram.entitlements` и `StrainWidgets.entitlements`. Бесплатные учётные записи App Group обычно не выдают: тогда контейнер недоступен, виджет показывает заглушку, а всё остальное работает как прежде. Чтобы отказаться от него совсем, достаточно убрать `CODE_SIGN_ENTITLEMENTS` у обеих целей.

Расширению нужен собственный bundle id `com.texasprogram.app.widgets`. При подписи бесплатным Apple ID это отдельный App ID, а их лимит — 10 за 7 дней; если Sideloadly откажется ставить сборку с расширением, цель `StrainWidgets` можно исключить из схемы.

## Запуск в Xcode

1. Клонируйте репозиторий на Mac.
2. Откройте `TexasProgram.xcodeproj` в Xcode 16.2 или новее.
3. Выберите симулятор iPhone с iOS 17+ и схему `TexasProgram`.
4. Нажмите Run. Для запуска на физическом iPhone выберите свою Development Team в Signing & Capabilities.

Тесты запускаются через Product → Test. На Mac с установленным симулятором их можно запустить командой:

```bash
xcodebuild test \
  -project TexasProgram.xcodeproj \
  -scheme TexasProgram \
  -destination 'platform=iOS Simulator,name=iPhone 15,OS=latest' \
  CODE_SIGNING_ALLOWED=NO
```

## Получение IPA через GitHub

1. Создайте пустой репозиторий на GitHub и загрузите туда содержимое проекта.
2. Откройте Actions → `iOS build` → Run workflow. Ручной запуск собирает IPA сразу; тесты запускаются отдельно только для Pull Request и не блокируют сборку.
3. После завершения откройте запущенный workflow и скачайте artifact `TexasProgram-unsigned`.
4. Распакуйте ZIP artifact — внутри будет `TexasProgram-unsigned.ipa`.

Workflow не хранит сертификаты, provisioning profile или пароль Apple ID. IPA специально остаётся неподписанным. Старый каталог `TexasProgram/Assets.xcassets` удаляется только во временной копии GitHub runner перед сборкой; `AppIcons.xcassets` с пользовательскими иконками сохраняется и компилируется.

## Установка через Sideloadly

1. Установите Sideloadly на Windows или macOS и подключите iPhone кабелем.
2. Перетащите `TexasProgram-unsigned.ipa` в окно Sideloadly.
3. Введите Apple ID и нажмите Start. Пароль передаётся Apple для подписи; при включённой двухфакторной защите следуйте подсказкам Sideloadly.
4. На iPhone включите Developer Mode, если система попросит, и доверьтесь профилю в Settings → General → VPN & Device Management.

При бесплатном Apple ID приложение обычно требуется переподписывать каждые 7 дней; точный срок и ограничения определяет Apple. Платная учётная запись разработчика обычно даёт более долгий срок подписи.

## Важное замечание

Стартовые 100 кг — демонстрационные значения. Перед тренировками обязательно протестируйте реальный 5ПМ для приседаний, жима лёжа и становой тяги. Программа не заменяет консультацию тренера или врача.
